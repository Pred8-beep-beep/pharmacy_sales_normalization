Проект: Нормализация и анализ данных аптечных продаж (май 2026)

Описание проекта
Бизнес-проект: очистить сырую, некорректную выгрузку транзакций продаж аптечной сети и построить аналитическую отчетность по региональным округам для коммерческого директора.  

Какие IT-задачи были решены:
1.Преодоление технических сбоев (ETL/чистка данных):
- Устранен сбой кодировки данных (перевод строки из некорректного стандарта в Юникод UTF-8).
- Выявлен и вручную устранен системный баг в "съехавших строк", вызванный наличием символа разделителя (';') внутри пользовательских комментариев.
- Проведен аудит пропущенных критических бизнес-ключей (пропуски ID аптек и транзакций).
